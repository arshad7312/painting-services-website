# Hue & Home

A responsive, single-page home-painting website concept for Bengaluru. The visual direction and copy are original; the supplied brands were used only as market references.

## Run locally

Open `index.html` in a browser, or serve this directory with any static web server. The site has no build step or package dependencies.

## Before launch

- Replace the Hue & Home name, copy, service details, and imagery with the customer's actual brand and approved claims.
- Connect the consultation form in `script.js` to a real lead endpoint or CRM. The current form validates input and displays a demo confirmation; it does not transmit or store enquiries.
- Confirm service areas, consultation terms, privacy wording, and phone-number validation for the business.
- The room illustrations are original local SVG assets, so the page does not rely on third-party image or font services.

The page includes service overviews, a three-step process, an accessible FAQ, responsive navigation, and a consultation form.
